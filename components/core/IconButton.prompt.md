Icon-only button for toolbars, table rows, card headers and dialog dismissals.

```jsx
<IconButton icon="x" label="Cerrar" />
<IconButton icon="download" label="Descargar reporte" variant="outline" />
```

Boxes are 32 / 40 / 48px — never smaller than 32 on desktop or 44 on touch. `label` is required.

The standard Grupo E2 action control — navy by default, orange only for the single most important conversion on a screen.

```jsx
<Button variant="primary" iconRight="arrow-right">Agendar diagnóstico</Button>
<Button variant="secondary" size="sm">Ver servicios</Button>
<Button variant="inverse" iconLeft="phone">Contactar</Button>
```

Variants: `primary` (navy fill, default), `accent` (orange — max one per view), `secondary` (navy hairline outline), `ghost` (quiet, for toolbars), `inverse` (white fill, for navy sections). Sizes 34 / 42 / 52px tall. Press state scales to .985; hover darkens one ramp step. Never stack two orange buttons together.

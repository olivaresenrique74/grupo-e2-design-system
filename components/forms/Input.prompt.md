Labelled single-line field with optional inner icon and suffix.

```jsx
<Input label="Correo corporativo" type="email" placeholder="nombre@empresa.com" iconLeft="mail" required />
<Input label="Facturación mensual" suffix="MXN" hint="Aproximado, sin IVA." />
```

Focus is a navy border plus a 3px navy 12% halo — the orange focus ring is reserved for keyboard `:focus-visible` on non-input controls.
